# AI Logging Agents Docs

This folder captures project context from the Codex sessions so a new session can quickly resume work without re-discovering the same decisions.

Start here in a new session:

1. Read [context-for-new-session.md](context-for-new-session.md).
2. Read [project-overview.md](project-overview.md) for scope and constraints.
3. Read [architecture.md](architecture.md) before changing code.
4. Read [runbook.md](runbook.md) before running or testing the app.
5. Read [next-steps.md](next-steps.md) for pending work.

Session history lives in [session-history.md](session-history.md).
